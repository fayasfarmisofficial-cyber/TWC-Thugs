TWC THUGS · amu

Anti-Messup · built on the Entire CLI · Bengaluru Tech Week Buildathon 2026 · Track 2 Graph Intelligence

Agents break what they can't see. amu builds the blast map from entire graph impact, turns it into an ordered contract, gates every phase with entire graph diff, and closes the loop with a sweep, doc candidates and a self-renovating CLAUDE.md memory block. Nothing is sound without a resolved graph edge; every guessed/unknown node carries a reason and a verify action; no output ever says safe/clean/verified.
